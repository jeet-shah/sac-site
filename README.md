# SAC Web Application

Frontend demo implementation for the Sports Activities Centre (SAC) platform at BITS Pilani, Goa Campus.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui
- Zustand
- React Query

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

Current implementation focuses on frontend architecture and mock-data-first development as part of the SAC demo sprint.
